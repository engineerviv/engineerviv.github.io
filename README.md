---

## ✨ Features

- **Dark / Light Mode** — toggle persisted via `localStorage`
- **Scroll Progress Bar** — gradient bar at the top of the page
- **Custom Animated Cursor** — dot + lagged ring, expands on interactive elements
- **Typed Animation** — cycles through AI/LLM expertise areas
- **Project Detail Modals** — click any project card to see tech stack, features, and links
- **GitHub Stats** — live stats and top-languages cards in the About section
- **Certifications Section** — dedicated section between Education and Work
- **Categorized Skills** — 29 skills grouped into 8 categories (Generative AI first)
- **Staggered Hero Animation** — `fadeUp` entrance on load
- **Particle.js Background** — interactive particle canvas on the hero section
- **ScrollReveal Animations** — elements animate in as you scroll
- **3D Tilt Effect** — VanillaTilt on project cards and profile image
- **Contact Form** — EmailJS integration for direct email delivery
- **Fully Responsive** — mobile hamburger menu, adaptive grid layouts
- **Live Chat** — Tawk.to widget
